# Тесты

Тесты используют `unittest`, FastAPI `TestClient` и временные каталоги. Они проверяют маршруты, поддержку JPG/PNG/GIF, валидацию содержимого, лимит размера, уникальность имён, каталог и логирование.

Установите зависимости и запустите из корня проекта:

```bash
python -m pip install -r requirements.txt
python -m unittest
```
