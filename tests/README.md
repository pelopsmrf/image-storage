# Тесты

Тесты используют `unittest`, FastAPI `TestClient` и временные каталоги. Они проверяют маршруты, поддержку JPG/PNG/GIF, валидацию содержимого, лимит размера, уникальность имён, сохранение метаданных, список изображений с пагинацией, удаление по id, обработку ошибок базы данных и логирование. Вместо PostgreSQL используется `FakeRepository` — таблица в памяти с тем же интерфейсом, что у `db.ImageRepository`.

Установите зависимости и запустите из корня проекта:

```bash
python -m pip install -r requirements.txt
python -m unittest
```
